# 나만의 프롬프트 관리 프로그램

이전 미션에서 작성한 프롬프트를 카테고리별로 분류하고, 검색하고, 즐겨찾기로 관리할 수 있는 Python 콘솔 프로그램입니다.
메모장, 노션, 메신저에 흩어져 있던 프롬프트를 한곳에서 찾아 쓰기 위해 만들었습니다.

## 실행 환경

- Python 3.10 이상
- 외부 라이브러리 없음 (Python 기본 문법만 사용)

## 실행 방법

1. 저장소 내려받기: `git clone https://github.com/42Seoul-soul/practice.git`
2. 폴더로 이동: `cd practice`
3. 프로그램 실행: `python main.py`

실행하면 메뉴가 나오고, 번호를 입력해 원하는 기능을 선택합니다.

## 기능 목록

| 번호 | 기능 | 설명 |
|---|---|---|
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 입력해 새 프롬프트를 등록 (빈 값은 다시 입력 요청) |
| 2 | 프롬프트 목록 | 등록된 모든 프롬프트를 번호, 카테고리, 즐겨찾기(⭐)와 함께 표시 |
| 3 | 카테고리별 조회 | 선택한 카테고리의 프롬프트만 표시 |
| 4 | 프롬프트 검색 | 제목 또는 내용에 키워드가 포함된 프롬프트 검색 |
| 5 | 프롬프트 상세 보기 | 번호를 입력해 프롬프트 전체 내용 확인 |
| 6 | 즐겨찾기 관리 | 번호를 입력해 즐겨찾기 추가/해제 |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 모아서 표시 |
| 0 | 종료 | 프로그램 종료 |

- 잘못된 번호를 입력하면 안내 메시지 후 메뉴로 돌아갑니다.
- 데이터는 프로그램 실행 중에만 유지되며, 종료하면 초기화됩니다.

## 프롬프트 카테고리

| 카테고리 | 설명 |
|---|---|
| 텍스트 생성 | 글쓰기, 기획안, 요약 등 텍스트 결과물을 만드는 프롬프트 |
| 이미지 생성 | 이미지 생성 AI에 넣는 장면 묘사, 스타일 키워드 |
| 영상 생성 | 영상 생성 AI용 장면 연출, 카메라 움직임 지시 |
| 페르소나 | AI에게 특정 역할이나 전문가 성격을 부여하는 프롬프트 |
| 자동화 | 노코드 자동화 도구와 함께 쓰는 프롬프트 |
| 기타 | 위 분류에 속하지 않는 프롬프트 |

카테고리는 목록에서 선택하거나 직접 입력해 새로 만들 수 있습니다.

## 코드 구조

기능별로 함수를 나누어 작성했습니다.

| 함수 | 역할 |
|---|---|
| show_menu() | 메뉴 출력 |
| add_prompt() | 프롬프트 추가 |
| show_list() | 전체 목록 출력 |
| show_by_category() | 카테고리별 조회 |
| search_prompt() | 키워드 검색 |
| show_detail() | 상세 보기 |
| toggle_favorite() | 즐겨찾기 추가/해제 |
| show_favorites() | 즐겨찾기 목록 |
| main() | 메뉴 반복 실행 및 기능 연결 |

## Git 작업 방식

- 기능 하나를 완성할 때마다 커밋했습니다.
- 프롬프트 목록 기능은 feature/list 브랜치에서 작업한 뒤 main에 병합했습니다.
